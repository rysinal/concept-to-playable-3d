# 多视角建模对照

用于人物制作中防止轮廓、五官、头发和材质逐轮偏离。参考图通过 [人物一致性检查](character-detail-workflow.md) 后，贯穿制作反复使用；不能生成后只看一次。

## 固定三类图的职责

- **原始参考与已选母版**：角色身份、比例和设计依据。
- **imagegen 目标图**：展开为有体积和材质的 3D 渲染风格多视角图、局部细节图。它们仍是二维图，不保证来自同一个真实 3D 模型；先查视角间结构是否兼容。
- **实际结果图**：从当前 `.blend` 或游戏引擎直接输出。保留原始文件；任何 imagegen 修图结果只能标作设计建议，不能代替实物验收。

## 按同条件成对检查

| 检查层次 | 目标参考 | 实际结果 |
| --- | --- | --- |
| 整体 | 正、侧、背面的统一比例和姿势 | 对应视角全身灰模 |
| 形体 | 头部和部位的体积、连接关系 | 对应视角局部灰模近景 |
| 表面 | 中性光下皮肤、头发、布料、金属目标 | 中性光下无光照颜色与完整材质 |
| 使用效果 | 目标镜头、距离下的角色外观 | 真实引擎截图与动作检查 |

记录 Blender 相机、姿势、分辨率和材质模式以便复拍。尽量匹配参考的投影与画面占比；参考若非严格正交，先识别相机差异，不把透视造成的偏差误判成错误几何。整体图与细节图保持同一角色左右定义。

每轮只改最明显的 1–3 项，记录“部位 → 可见差异 → 几何/UV/材质/相机原因 → 修改动作 → 复查图”。例如：鼻翼侧面过厚，先修鼻翼体积，再检查正面宽度及整脸比例；不能仅换高光使侧面看起来更薄。

先对照局部，再回到整体；修正一个视角后检查相邻视角，防止正面相似但侧面塌陷。不能为了单张参考而破坏其他通过的视角。参考互相矛盾时先修参考，不强行扭曲模型。

## 生图在迭代中的用途

资料足够时优先修改模型，目标图不随模型当前结果一起漂移。只有遇到未解释的结构、不可兼容视角或用户改变设计时才补图/修图，并标记受影响的下游参考待复查。

可以把原图、母版和当前模型截图一起传给 imagegen，请它画出具体部位的修正意图；但图中只改变指定部位、保留已经正确的比例和风格。输出记录为“修正目标”，再由 Blender 实现并重新渲染。

对照由能查看图像的 Codex 完成，不能把图片生成接口当作已经执行的质量评测。图片相似度或主观评分不是拓扑、UV、绑定或性能通过的证据；这些检查仍在真实模型和运行时完成。

交付同一版本的“目标图＋实际结果图”、本轮差异与修复状态，并标明哪些隐藏部位是补充设计。参考图包任务无需为了这套验收创建模型，直接说明尚未进行模型对照。
