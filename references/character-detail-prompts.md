# 人物细节生图提示词

模板按实际任务填写。明确每个输入图片的角色，并实际传入工具；不要仅在文字中声称已提供。提示词的视角和部件按需要调整，不默认批量生成全部图。

## 统一人物母版

```text
输入图 1 是人物身份、风格、服装和配色的依据。
生成用于 3D 建模的统一人物设定图：正面、严格侧面、背面，
同一角色、同一中性站姿、相同尺度和基线，近似正交表达，干净背景与中性光。
保留：[脸型/发型轮廓/服装层次/饰品佩戴侧/颜色等实际已知特征]。
以角色自身的左右为准，不镜像不对称饰品。
隐藏部分按 [明确的补充设计] 表达，不能改变原图可见的设计。
不要戏剧性光影、景深、夸张透视或让头发遮住需要建模的关键结构。
保持足够清楚的脸和手；不加入无依据的精确尺寸或说明文字。
```

## 局部细节通用骨架

```text
输入图 1 为原始人物，图 2 为已选定多视角母版，图 3 为相关局部/当前模型（如有）。
只展开 [部位] 的建模参考，不重新设计角色。
需要的视角：[能解释结构的视角]；保持相同尺度与结构，中性光与干净背景。
必须保持：[从原图和母版提取的具体不变项]。
本图要解决：[明确的几何/材质/连接问题]。
显示相邻部位的少量上下文，以便确认连接位置。
不能更改脸型、年龄感、发色、衣层、饰品数量或佩戴侧。
```

## 头发补充要求

```text
显示发际线、分缝、前后层次以及主发束从发根到发梢的走向。
包含 [前/侧/后/顶中必要的视角]，让发束有体积而非只有表面条纹。
保持 [直发/波浪/卷发、粗细、长度、颜色和风格]。
将轮廓与流向说明、局部发质参考分为清楚区域；不要增加无法对应的发束。
```

## 五官补充要求

```text
展示同一个头部的正面、侧面、四分之三视角，
重点观察 [眼睑包裹眼球/鼻梁鼻翼/嘴唇与口角/耳廓耳根]。
保留原脸的年龄感、比例与风格，不美容重塑、不改变种族外观。
按需要另做 [闭眼/微张嘴] 结构参考，明确它是状态变化，
不要把新的面部结构或口腔推断说成原图已经提供。
```

## 衣服与饰品补充要求

```text
展示 [服装层次或饰品] 的正面、侧面和 [背面/连接面]。
明确 [领口袖口/接缝/扣件/厚度/附着点]，保留配色、材质和佩戴方向。
视图中展示连接到身体或服装的方式，不只画悬空的孤立装饰。
面料纹理和褶皱要符合 [材质与静止姿态]；不要把所有细节变成金属浮雕。
```

## 单张图的一致性修正

```text
图 1 为原图，图 2 为通过检查的母版，图 3 是待修局部图。
只修图 3 的 [具体差异]，以原图和母版为依据。
保留已经正确的 [列出关键项]；保持原有视角、画幅和其他部位。
不要重设计角色，不增加新的饰品或衣层。
```

## 用局部参考指导建模与复查

可将目标表达为“中性光下的 3D 渲染风格参考”，但输出仍是二维设计图。需要同条件模型对照时读取 [多视角建模对照](character-visual-comparison.md)。

```text
参考 [部位 ID 和实际图片] 修整模型中的 [已确认对象]。
先修轮廓、体积和连接关系，保留已经通过的其他部位。
按相同视角输出灰模和完整材质近景，对照原图、母版与部位图。
如果图之间互相矛盾，先定位矛盾；不要用增加细分、强光或贴图噪点掩盖。
报告解决了哪个差距，以及 UV、贴图、变形哪些已检查、哪些未检查。
```
